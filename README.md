# Quantum Computing Learning Repository

This repository contains my journey and notes on quantum computing, with a focus on IBM's Qiskit SDK. The content is based on various learning resources including:

- IBM Qiskit tutorials
- IBM Quantum Summer School
- IBM Learning Quantum platform
- Additional self-directed learning

## Repository Structure

### 📚 Notes and Documentation

- `overview.md` - High-level introduction to quantum computing concepts
- `notes/` - Detailed notes on specific topics
  - `noise_notes.md` - Understanding quantum noise and its effects
  - `qc_inpractice.txt` - Practical considerations in quantum computing

### 💻 Example Circuits and Algorithms

The `example_circuits/` directory contains Jupyter notebooks demonstrating various quantum computing concepts and algorithms:

- `hello_world.ipynb` - Basic Qiskit introduction
- `quantum_teleportation.ipynb` - Implementation of quantum teleportation
- `grovers_algo.ipynb` - Grover's search algorithm
- `deutsch-joza.ipynb` - Deutsch-Jozsa algorithm
- `max_cut_problem.ipynb` - Quantum solution to the MaxCut problem
- `chsh_proof.ipynb` - CHSH inequality demonstration
- `performance_on_noisy_computer.ipynb` - Analysis of quantum circuit performance with noise
- `tests.ipynb` - Various quantum computing tests and experiments

### 🔧 Qiskit Implementation

The `qiskit/` directory contains specific implementations and experiments using the Qiskit framework.

## Getting Started

To run the notebooks in this repository, you'll need:

1. Python 3.x
2. Qiskit SDK
3. Jupyter Notebook or JupyterLab
